# 三国·卡牌炫技对决（Sanguo Card Duel）

语音对战 H5 卡牌小游戏，免费即玩，支持 **中文 / English / 日本語** 三语。

## 玩法
- 语音蓄力出手：麦克风音量越大，攻击越强（拒绝麦克风授权时自动回退到点击/按键模式）
- 三连胜解锁进阶模式（语音对战 / 解压屋）
- 多语言界面，移动端适配

## 技术
- 纯前端 H5（无构建步骤）：`home.html` 入口 → `index.html` 游戏主程序
- 美术资源位于 `art/`（卡面 / 关键图 / 立绘）
- 部署产物即本目录，可直接托管为静态站

## 仓库说明
本仓库为游戏的静态发布版本。`webroot/` 即线上运行的全部文件。

## 本地预览
直接用浏览器打开 `home.html` 即可（建议通过本地静态服务器以避免音频采集的跨域限制）。

```
npx serve .
```
